# CleanTech Finance v0.5.0 发布说明

发布日期：2026-08-04

## 本版结论

v0.5.0 把交易执行与初步估值接入本地 FA 工作站，并在公开 Vercel 预览中增加一个不上传、不保存的浏览器本地估值沙盒。两者不是同一信任层：

- **本地受控版**是正式工作流入口，使用来源化输入、服务端确定性重算、不可变版本、哈希、人工复核、内部批准和 XLSX 导出。
- **公开浏览器版**只用于快速算术与交互演示，输入仅驻留当前页面内存，不进入来源链、版本链或审批链，状态最高为 `screen_grade`。

本版不输出投资建议、信用评级、综合风险评级、正式估值意见或公平性意见，也不把多个估值方法加权成一个总分。

## 新增能力

### 本地交易与估值工作流

- Deal 与 Company/Case 分离，分别记录买方、标的、交易范围、币种、估值日、负责人和保密等级。
- 人工确认的交易阶段、理由、幂等键、revision 和记录哈希。
- 来源化、人工确认的估值输入与不可变版本链。
- FCFF DCF：Downside / Base / Upside、期末或年中折现、永续增长终值及退出倍数交叉检查。
- Trading Comps：企业价值倍数和 P/E 的正确分子口径、N/A、N/M、排除理由和异常值披露。
- EV→Equity 桥接、完全摊薄股数与每股价值。
- WACC×终值增长率、WACC×退出倍数敏感性。
- Calculation Integrity 与 Decision Readiness 独立显示。
- FA review、内部使用批准、审计记录和无宏、无外链的确定性 XLSX 导出。

### 公开浏览器本地初算

- 五年 FCFF DCF、WACC、终值增长率、期末/年中折现。
- 现金、债务、其他债权和完全摊薄股数的 EV→Equity 桥接。
- 每股价值与终值集中度提示。
- WACC×终值增长率控制区间与方向检查。
- 默认折叠、需主动启用的自填倍数交叉检查；结果与 DCF 独立显示。
- CSP `connect-src 'none'`、无浏览器存储、无 Cookie、无上传和无第三方依赖。

## 重要修正

- 统一同行比较门槛：少于 **5** 个有效、已确认的外部可比样本时，不输出 P25/P75、百分位估值区间或其派生目标区间；仅保留样本数、中位数、均值和明确的 `insufficient_sample` 边界。
- 敏感性区间中任何 `WACC <= g` 单元格都会使 Calculation Integrity 失败，并把 Decision Readiness 降为 `not_ready`。
- 浏览器不能提交计算结果；本地服务只从当前不可变输入版本重新计算。

## 仍未实现

- 线上多人身份、租户/Deal 权限、持久数据库与对象存储。
- Precedent Transactions、项目级 DCF/NAV、Reverse DCF。
- 当前网页中的完整三年历史、LTM、3–5 年预测财务合同编辑器和逐字段来源编辑。
- 真实交易参考模型的逐单元格 tie-out。

## 升级与验证

- Python 包版本、运行时 `__version__`、Citation 元数据和估值工作簿应用版本同步为 `0.5.0`。
- 发布前必须运行 Ruff、完整 Pytest、浏览器估值专项测试和公开站响应式/网络边界检查。
- 历史 v0.4 交接和验证文档保持原版本号，不做全局替换。
