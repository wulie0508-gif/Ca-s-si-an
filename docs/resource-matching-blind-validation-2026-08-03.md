## 关键通过项

1. 两次完全相同输入的 9,600 个直接调用结果逐项一致。
2. 课程的发布状态、活动状态、有效期和模拟数据披露合约均为硬门槛。
3. 导师的授权、冲突、可用性、有效期和核心能力命中均为硬门槛；地域相同不能单独构成候选理由。
4. 模拟导师统一为不可联系、不可自动分配；模拟课程不可自动报名。
5. `candidate_pending_review` 政策更新不会进入已确认政策匹配。
6. HTTP 无令牌、伪造令牌、错误 scope 和撤销后的令牌均返回 `403`。
7. `resource:read` 令牌不能调用 `resource:match`；完整授权可以读取资源并匹配课程和导师。
8. 资源匹配端点拒绝把 `policy` 伪装为课程或导师匹配请求。
9. 输出中没有肯定式自动执行、事实升级、自动评级或综合评分字段。

盲测之后又增加了一个权限回归：授权请求和人工批准阶段都明确要求 `resource:match` 必须同时包含 `resource:read`。这项修复由仓库内回归测试持续覆盖，不属于上述原始 JSON 报告的 39,604 次断言。
