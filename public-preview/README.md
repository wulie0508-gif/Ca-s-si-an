# CleanTech Finance · 静态设计预览

这是一个可独立部署的纯静态 UI 预览，用于评审 CleanTech Finance 的信息架构、视觉层级、响应式和键盘交互。

## 真实边界

- 页面只包含 `Synthetic demo / 合成演示` 数据。
- 不包含真实企业、交易、政策、课程、导师或内部材料。
- 不读取或写入浏览器存储。
- 不发起任何网络请求，也不依赖第三方字体、脚本、图片或服务。
- Deals 页面提供浏览器本地 DCF 初算和自填倍数交叉检查；预填值全部为合成数据，用户输入只驻留当前页面内存。
- 公开初算不绑定来源、不生成版本哈希、不保存、不复核、不批准，也不等同于本地受控版的确定性估值工作流。
- 上传、保存、授权、自动匹配、人工复核与发布操作均被禁用；这些能力只属于本地受控版。
- Deals 的四项 readiness 独立显示，不加权、不汇总，也不输出投资、信用或综合风险评级。
- DCF 与自填倍数结果独立展示，不机械加权为综合估值；计算完整性与决策可用性分开显示。
- 政策条目只是字段与交互样例，不对应官方文件；正式使用必须核验官方原文。

## 文件

- `index.html`：Home / Companies / Deals / Resources 四个视图及语义结构。
- `styles.css`：冷白、炭黑和克制 teal 的响应式设计系统。
- `valuation-calculator.js`：无网络、无持久化的 DCF 初算、EV→Equity 桥接、敏感性与自填倍数交叉检查。
- `app.js`：纯本地路由、筛选、详情选择、键盘 tabs 与估值结果渲染。
- `vercel.json`：CSP、noindex、nosniff、frame、referrer 与 permissions 安全响应头。
- `robots.txt`：阻止搜索引擎抓取。

## 本地预览

可用任意静态文件服务器把当前目录作为站点根目录。不要直接双击文件模拟生产行为，因为响应头只能由服务器返回。

示例：

```text
python -m http.server 4173
```

然后访问本机的 4173 端口。

## Vercel 部署

在 Vercel 项目设置中把 Root Directory 指向 `public-preview`，框架预设选择 Other，不需要构建命令。部署前应再次确认项目没有被配置为公开索引；本目录同时提供 `robots.txt`、页面 robots meta 和 `X-Robots-Tag` 三层 noindex。

## 验收尺寸

至少检查 320、390、768、1024 和 1440 像素宽度：

- 页面级没有横向滚动；局部 tabs 可以横向浏览。
- 所有可交互控件触控高度至少 44 像素。
- 键盘可完成主导航、企业筛选、交易选择、Deals tabs 和 Resources tabs。
- 焦点始终可见，路由切换后页面标题获得焦点。
- 系统启用 reduced motion 时不依赖动画传达状态。

## 非生产系统

该目录用于视觉、交互和 screen-grade 算术评审。它不是 CleanTech Finance 的生产前端，也没有 API、持久化、身份验证、来源链、版本链、人工批准或真实业务数据处理能力。正式估值仍应在本地受控版完成输入确认、服务端重算、版本哈希、复核和导出。
